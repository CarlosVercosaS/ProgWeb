A linguagem HTML

HTML (abreviação para a expressão inglesa HyperText Markup
Language, que siginifica Linguagem de Marcação de Hipertexto)
é uma linguagem de marcação utilizada na construção de páginas
na Web. Documentos HTML podem ser interpretados por
navegadores.

Alguns dos recursos da linguagem HTML vistos até este momento:

Recrusos Tags associadas Descrição
Links <a> Criar links entre paginas
Listas <ul> e <li> Criar lista de itens ordenados
<ol> e <li> Criar lista de itens nao ordenados
Imagens <img> Inserir imagens
